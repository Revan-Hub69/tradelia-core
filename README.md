# Tradelia Core

Fondazione UI per una piattaforma educativa focalizzata su percorsi di decisione finanziaria consapevole.

## Requisiti
- Node.js 18+
- npm

## Comandi principali
- `npm install` – installa le dipendenze.
- `npm run dev` – avvia l'app Next.js in sviluppo.
- `npm run build` – build di produzione.
- `npm run lint` – linting con la configurazione Next.

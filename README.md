# Tradelia

Homepage istituzionale per la verifica di compatibilita tra obiettivi dichiarati
e caratteristiche reali degli strumenti finanziari. Nessuna raccomandazione
operativa, nessun ranking, nessuna pressione all'azione.

## Sviluppo locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run start
```

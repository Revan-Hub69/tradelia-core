# Legacy Archive

Questa cartella contiene file storici spostati fuori dalla root per ridurre rumore operativo.

## Contenuto

- `legacy/root-artifacts/` → documenti e trigger storici non canonici.
- `legacy/sql/` → setup SQL legacy mantenuti a scopo storico.

## Regola

Nessun file in `legacy/` è source-of-truth per il prodotto attivo, salvo revisione esplicita.

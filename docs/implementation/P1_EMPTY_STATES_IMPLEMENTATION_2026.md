## 1. Research Tier-1: Best Practices 2026

### Empty State Design Principles

**Source**: [Eleken - Empty State UX](https://www.eleken.co/blog-posts/empty-state-ux)

> In SaaS products, empty states crop up all over: the first time a user logs in, when a list or table has no entries, when a user clears out all items, or when something goes wrong.

**Source**: [Blush Design - Empty States Secret Sauce](https://blush.design/blog/post/empty-states)

> An empty state is a moment in a user's experience when there is "nothing" to display. They are interface screens that have little to no content on them.

**Source**: [Carbon Design System - Empty States Pattern](https://carbondesignsystem.com/patterns/empty-states-pattern/)

> Empty states are moments in an app where there is no data to display. They are most commonly seen the first time a user interacts with a product or page.

**Source**: [This Design Girl - Designing Empty States](https://thisdesigngirl.com/ui-design/empty-state-design/)

**Poi può scegliere**:
- Yield (7 moduli nuovi)
- Invest (7 moduli nuovi)
- Speculate (14 moduli nuovi: Invest + Speculate)

### Scenario 2: Utente inizia da "Invest"
1. Completa Fase 0A (4 moduli)
2. Completa Fase 0B (3 moduli)
3. Completa Fase 1 - Own (7 moduli) - prerequisito
4. Completa Fase 3 - Invest (7 moduli)
5. **Totale**: 21 moduli

**Poi può scegliere**:
- Yield (7 moduli nuovi)
- Speculate (7 moduli nuovi, perché Invest già fatto)

1. Fase 0A + 0B (7 moduli) - una volta
2. Fase 1 - Own (7 moduli) - una volta
3. Fase 2 - Yield (7 moduli)
4. Fase 3 - Invest (7 moduli)
5. Fase 4 - Speculate (7 moduli)
6. **Totale**: 35 moduli core

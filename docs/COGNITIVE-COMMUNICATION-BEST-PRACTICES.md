# Best Practice Cognitive per Comunicazione Competizioni

## Ricerca e Fondamenti

### Principi di Carico Cognitivo (Sweller, 1988)
1. **Carico Intrinsico**: La complessità intrinseca del task
2. **Carico Esterno**: Come presentiamo l'informazione
3. **Carico Germano**: L'effort per costruire comprensione

**Obiettivo**: Minimizzare carico esterno, ottimizzare carico germano

### Legge di Miller (7±2)
- Non più di 7 elementi per gruppo
- Idealmente 3-5 elementi per sezione
- Chunking: raggruppare informazioni correlate

### Gerarchia Visiva e Scanning Pattern
- Pattern a "F" per lettura web
- Pattern a "Z" per landing page
- Gli utenti scansionano, non leggono

## Struttura Ottimale per Drawer Competizione

### 1. Sequenza Informativa (Progressive Disclosure)

```
PRIORITÀ 1 - Decisione Immediata ("Devo partecipare?")
├── Cosa è (hook emotivo)
├── Quando (date chiave)
├── Quanto costa / Quanto si vince
└── CTA principale

PRIORITÀ 2 - Requisiti ("Posso partecipare?")
├── Chi può partecipare
├── Requisiti tecnici
├── Strumenti disponibili
└── Restrizioni

PRIORITÀ 3 - Come funziona ("Come vinco?")
├── Regole del gioco
├── Sistema di punteggio
├── Criteri di vittoria
└── Esempi pratici

PRIORITÀ 4 - Dettagli ("Ho bisogno di più info")
├── Regolamento completo
├── FAQ
├── Supporto
└── Termini legali
```

### 2. Principi di Comunicazione Chiara

#### A. Linguaggio
- **Parole semplici**: "Partecipa" vs "Registrati all'evento competitivo"
- **Verbi attivi**: "Vinci $1000" vs "È possibile vincere $1000"
- **Frasi corte**: Max 20 parole per frase
- **Evita gergo**: "Paper trading" → "Trading simulato con soldi virtuali"

#### B. Struttura
- **Titoli descrittivi**: Non "Regole" ma "Come si vince"
- **Bullet points**: Per liste (max 5 per gruppo)
- **Highlight visivi**: Per informazioni critiche
- **Spazi bianchi**: Aumentano leggibilità del 20%

#### C. Accompagnamento
- **Progress indicator**: "Passo 1 di 3"
- **Microcopy**: Testo che guida ("Inizia qui")
- **Feedback immediato**: Conferme visive
- **Next steps**: Sempre chiaro cosa fare dopo

### 3. Pattern Mentale dell'Utente

```
Fase 1: Attrazione (0-3 secondi)
└── "Questo è per me?"
    ├── Badge "Gratis" / "Premi $20K"
    ├── Immagine/Icona accattivante
    └── Headline emotiva

Fase 2: Valutazione (3-10 secondi)
└── "Ne vale la pena?"
    ├── Tempo richiesto
    ├── Skill necessarie
    ├── Rischi/Restrizioni
    └── Reward potenziale

Fase 3: Azione (10+ secondi)
└── "Cosa devo fare?"
    ├── Primo passo chiaro
    ├── CTA prominente
    └── Requisiti immediati
```

### 5. Anti-Pattern da Evitare

❌ **Muro di testo**: Paragrafi lunghi senza break
✅ **Chunking**: Informazioni in blocchi scansionabili

❌ **Gergo tecnico**: "Drawdown massimo", "Equity-based"
✅ **Linguaggio naturale**: "Perdita massima consentita"

❌ **Informazioni nascoste**: Requisiti importanti in fondo
✅ **Progressive disclosure**: Dalla più importante alla meno

❌ **Ambiguità**: "Potresti vincere"
✅ **Chiarezza**: "250 premi garantiti"

❌ **Friccione**: Troppi click per informazioni base
✅ **Immediata**: Info critiche visibili subito

### 6. Metriche di Successo

- **Time to understand**: < 30 secondi per capire di che si tratta
- **Decision time**: < 2 minuti per decidere se partecipare
- **Action rate**: % utenti che cliccano CTA dopo aver letto
- **Bounce rate**: % che chiude senza interagire

### 7. Checklist Implementazione

- [ ] Headline chiara in < 10 parole
- [ ] 3-5 bullet points per sezione
- [ ] CTA visibile senza scroll
- [ ] Date importanti evidenziate
- [ ] Requisiti di idoneità in evidenza
- [ ] Sistema di punteggio spiegato semplicemente
- [ ] Premi visualizzati gerarchicamente
- [ ] Link a regolamento completo per chi vuole approfondire
- [ ] Supporto/contatti facilmente accessibili

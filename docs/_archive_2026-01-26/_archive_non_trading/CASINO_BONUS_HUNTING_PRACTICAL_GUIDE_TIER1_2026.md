### 1.2 La Matematica del Bonus Hunting

**Formula Expected Value (EV)**:
```
EV = Bonus Value - (Wagering × House Edge)
```

**Esempio pratico**:
```
Bonus: €100 (100% match su deposito €100)
Wagering: 30x bonus = €3,000
Gioco: Slot RTP 97% (house edge 3%)

Calcolo:
Loss atteso = €3,000 × 3% = €90
Bonus ricevuto = €100
EV netto = €100 - €90 = +€10

ROI = €10 / €100 deposito = 10%
```

**Quando un bonus è +EV**:
```
Bonus > (Wagering × House Edge)

Esempio break-even:
€100 bonus, 30x wagering, 3% house edge
€100 = €3,000 × 0.03
€100 = €90 ✅ Positivo

€100 bonus, 50x wagering, 3% house edge
€100 = €5,000 × 0.03
€100 < €150 ❌ Negativo
```

#### Calcolo EV Rapido

**Formula semplificata**:
```
EV% = (100 / Wagering Multiplier) - House Edge%

Esempio:

EV% = (100 / 30) - 3 = 3.33% - 3% = 0.33%

Su €100 bonus: €0.33 profit atteso
```

**Definizione**: Bonus per depositi successivi al primo.

**Perché sono migliori**:
- Meno competizione
- Spesso wagering più basso
- Casino già ti conosce (meno controlli)

Secondo deposito: €100 → Bonus €50 (20x)

EV totale: €100 - €105 + €50 - €30 + €30 - €22.5 = €22.5
```

**Strategia**: Completare welcome, poi aspettare reload via email.

### 3.3 Cashback Programs

**Definizione**: Rimborso percentuale sulle perdite.

**Matematica**:
```
Gioco: Slot RTP 97%
Cashback: 10% sulle perdite

Loss atteso su €1,000: €30
Cashback: €30 × 10% = €3
EV netto: -€30 + €3 = -€27

Ancora negativo, ma migliore del normale
```

**Quando è +EV**:
```
Cashback > House Edge

Esempio:

Cashback 5%

Su €1,000:
Loss: €20
Cashback: €50
Profit: +€30 ✅
```

**Realtà**: Cashback >5% è raro, ma esiste in VIP programs.

2. **Low wager FS**: Vincite con 10-20x wagering
3. **High wager FS**: Vincite con 35-50x wagering (AVOID)

```
